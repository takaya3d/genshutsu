# 発注書 — DeepPaint世界の現出(水墨タッチのWeb立体絵画)

この文書はClaude Codeへの正式発注である。CLAUDE.md(憲法)とAESTHETICS.md(美学)を先に読み、その掟の下でこの発注を執行せよ。

## 発注書(型)

```
像:   白い和紙の上に、筆致が「描かれた順」に一本ずつ現れ、水墨の世界が立ち上がる。
      カメラがわずかに動くと、筆致同士に視差があり、絵の中に奥行きがあることに気づく。
モード: 静
主役:  筆致そのもの(かすれ・入り抜き・濃淡)。ジオメトリは筆致の支持体にすぎない。
参照:  GAKU(多田学)のDeepPaint/立体絵画から「筆致が3D空間に住む」という構造だけ。
      見た目の複写はしない。原子(筆テクスチャ)は最終的に貴優の筆で置き換える。
判定:  ①スクリーンショットがEEVEEレンダーと並べて「同じ世界」に見えるか
      ②筆致に入り抜き(先細り)とかすれが存在するか
      ③余白が「グレーの無」ではなく「和紙」に見えるか
      ④reveal(描かれていく)に間(ま)があるか — 一斉描画は即没
```

## 中心原理(実装の背骨)

**筆致はシェーダーの効果ではなく、ジオメトリである。** Grease Pencilのストロークは「点列(位置・筆圧・描画順)を持つリボン」であり、これはWebに完全に移植可能。シェーダーで水墨「風」に見せるのではなく、筆致そのものを空間に置く。これがDeepPaint構造の核。

**描画順は作家の手の記録である。** GPデータはストロークの描かれた順序を保持している。reveal演出はこの順序を必ず使う。ランダム順や位置順で現すのは、作家の手を捨てる行為であり禁止。絵は「描かれた通りに、もう一度描かれる」。

## 工程と受入基準

### 1. 骨格(済とのこと。以下を満たすか確認だけせよ)
Vite + 最新three.js(ESM)。GLB読込。カメラは固定+微パララックス(ポインタで±数度)。orbit全開放は不要 — これは絵であり、絵に成立しない角度を観客に渡さない。

### 2. ストロークデータの搬入路(最重要工程)
GLB経由の焼きメッシュだけに頼らず、**ストロークをデータとして持ち込む道**を作る:
- Blender側: GPストロークを JSON にエクスポートするスクリプト(python)を書く。各ストローク = { points:[x,y,z,pressure,...], order, layer, inkDensity }。
- Web側: JSONからリボンを再構築する StrokeRibbon クラス。
  - 三角形ストリップ。幅 = pressure × ノブ。**両端は必ず幅0へ絞る(入り抜き)**。
  - UV.x = 弧長正規化(0→1)。これがreveal(uProgressでUV.x以降をdiscard/フェード)の軌道になる。
  - UV.y = 幅方向。筆テクスチャ(かすれのアルファ)を貼る。
- 点苔・飛沫用に StrokeStamp(インスタンス化した足跡クアッド)も用意。
- 筆テクスチャは暫定でノイズ生成でよいが、`textures/brush/` を貴優のスキャン差し替え口として明示的に分離しておくこと。

### 3. 墨のマテリアル
- 濃淡: 頂点アルファ(inkDensity×pressure) × NdotLではなく、**基本は無照明(MeshBasicMaterial系/カスタムShaderMaterial)**。水墨に光源は要らない。陰影が要る面は2〜3段の墨ランプで。
- かすれ: 筆テクスチャのアルファ + 弧長方向のノイズで、墨が切れる。
- にじみ: エッジのソフト化はテクスチャで持つ(ポストの全面ブラーで誤魔化さない)。

### 4. 和紙ポスト処理
レンダーターゲット1枚のフルスクリーンパスで:
- 和紙テクスチャの乗算(繊維ノイズ+粒状感。生成でよい)
- 余白 = 和紙の色(#f4eee2近辺)。純白・純グレー禁止。
- わずかなエッジ暗化(墨の溜まり)
- **boiling(揺らぎ)は消すな、打て。** ノイズシードを秒8コマ(≒3コマ打ち)で更新し、筆致の輪郭を微揺れさせる。リミテッドアニメの生命感として意図的に使う。ノブで0(静止)〜12コマまで可変に。

### 5. reveal(描かれていく)の振り付け
- グローバル uProgress(0→1)を、ストロークの order に沿って分配。
- stagger分配には必ずイージングをかける(等間隔禁止)。
- **章の間(ま)を設ける**: レイヤー(例: 山→霧→木→点苔)の切れ目で0.5〜1.5秒、何も描かれない時間を置く。
- 入力: まずはスクロール(戻せば絵が消えていく=可逆)。自動再生モードも用意。

### 6. EEVEE比較調整
- 同一カメラ・同一フレームでEEVEEレンダーとWebのスクリーンショットを並べたcompare.htmlを作る。
- 差分を言語化してledgerに記録(「Webは墨が均質すぎる」等)し、1項目ずつ潰す。
- 完全一致は目標ではない。**「同じ作家の絵に見える」が合格線。**

## 貴優ノブ(必ず一箇所に集約)
筆幅係数 / 入り抜きの絞り長 / かすれ強度 / boilingコマ数 / 和紙の強さ / reveal全体時間 / staggerカーブ / 章間の間の秒数 / パララックス角度

## 禁止
- ポスト一発(Kuwahara等)で「水墨風」に逃げること。筆致ジオメトリが主、ポストは紙。
- orbit全開放。一斉reveal。純白背景。DeepPaint成果物(コード・テクスチャ)の複写。
