# 分岐する火花パーティクル(線香花火の松葉)

源:     線香花火の観察+パーティクル系の一般原理(2026-07-26)。エージェント粒子の行動則の考え方
        (https://tympanus.net/codrops/2025/12/10/simulating-life-in-the-browser-creating-a-living-particle-system-for-the-untillabs-website/)から
        「粒子に寿命内イベントを持たせる」発想だけ借りた。コード複写なし。
原理:   火花の「松葉」は飛翔中の分岐で生まれる。各粒子に branchAt(寿命内の時刻)を持たせ、
        通過時に子粒子2〜4個を親速度±回転で生成(世代上限2)。相図はフェーズ関数P(u)一枚で制御
        (放出率・初速・分岐確率・重力・音の密度を寿命位置uで変える)。
        軌跡はフレームを消さず半透明の背景色クアッドを重ねる残像法が最も安い。
再実装: sketches/験/branching-sparks.html(クリックで火花一発、分岐あり、残像法)
モード適性: 静◯ 艶◎ 祭◎
親和タグ: 余韻 / 明滅 / 鎮まり(散り菊の間遠なまたたき) / 一生の相図
罠:     加算合成で白飛びしやすい。粒子サイズは2〜4pxに抑え、色は熱で白→橙→緋に落とす。
        残像クアッドにビネットを焼き込むと消え残りが出ない。プールは固定長で確保。
