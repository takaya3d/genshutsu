# モーダル合成(非整数次倍音の鈴)

源:     憲法の指示(風鈴=非整数次倍音のモーダル合成)+ 一般的な物理モデリング音響の原理 (2026-07-26)
原理:   打撃音 = その物体の固有モード(部分音)の重ね合わせ。ガラス鈴の部分音は整数倍にならない
        (例: f0×[1, 2.32, 3.85, 5.11, 6.4])。各モードを正弦波+指数減衰で合成し、
        高次ほど速く減衰させる。立ち上がりに短いバンドパスノイズを重ねると「ちん」の質感が出る。
        減衰の長い基音が「余韻」を作る——ここが間の設計と直結する。
再実装: sketches/験/modal-bell.html(クリック位置の高さでf0が変わる最小の鈴)
モード適性: 静◎ 艶◯ 祭△(連打すると品が落ちる。ストライク間隔に下限を)
親和タグ: 余韻 / 間 / 鎮まり / 音階(複数鈴のf0を和音に調律すると「気づき」になる)
罠:     部分音を整数比にすると鉄琴になってしまう。detuneを±0.3%入れると空気感が出る。
        AudioContextはユーザー操作後にしか始動できない(モバイル)。
