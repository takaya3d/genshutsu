# 封じた煙 — 有界ボリューム単パス行進

源:     https://www.shadertoy.com/view/tflBDM 「Chill Smoke Orb」(発見 2026-07-25。CC BY-NC-SA — 原理のみ、コードは一切見ずに再実装)
原理:   煙を「無限の霧」でなく有界領域(球・カプセル)に封じ、レイがその領域を貫く区間だけを短い歩数で行進する。
        各ステップでノイズ変調した密度場を積算し、1-exp(-Σ密度) で透過率に変換する(Beer-Lambert)。
        境界の外は即棄却できるため、画面の大半のピクセルがループに入らず、フルスクリーンでもモバイル60fpsが狙える。
再実装: sketches/験/bounded-volume-smoke.html(球に封じたfbm煙。歩数・密度・半径の3ノブのみの最小構成)
モード適性: 静◎ 艶◯ 祭△
親和タグ: 間 / 鎮まり / 余韻 / 一筋 / 蚊遣り / 線香 / 湯気 / 霧
罠:     ・フルスクリーンでfbmを歩数分呼ぶと重い — 密度の粗い見積りが閾値未満のステップではノイズ計算を跳ばすこと
        ・歩数が少ないと縞(バンディング)が出る — ステップ開始位置をピクセルごとにハッシュでずらすと消える
        ・境界の淵で密度をゼロに絞らないと「箱の中の煙」がバレる
