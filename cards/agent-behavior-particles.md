# 行動則エージェント粒子

源:     https://tympanus.net/codrops/2025/12/10/simulating-life-in-the-browser-creating-a-living-particle-system-for-the-untillabs-website/ (2026-07-25発見)
原理:   粒子を物理でなく「生態」で動かす。各エージェントは毎フレーム、行動則の合力で操舵する:
        徘徊(ノイズ由来の気まぐれ) + 分離(近すぎる仲間から離れる) + 壁回避(境界の内向き力)
        + 状況反応(脅威から逃げる/興味に近づく)。力は速度でなく「操舵(steering)」に効かせ、
        最高速度と旋回率に上限を置くと生き物の説得力が出る。イージング曲線は使わない——行動が間を作る。
再実装: sketches/験/agent-wander.html(徘徊+分離+円形壁回避の最小群)
モード適性: 静◎ 艶◯ 祭◯
親和タグ: 生態 / 間(休む個体を作る) / 鎮まり(脅威→散る→静けさ→戻る)
罠:     全員が常時動くと群れが「機械」になる。休止状態と個体差(速度・臆病さ)を必ず入れる。
        分離半径が大きすぎると群れがばらけ、境界力が強すぎると壁際で震える。
