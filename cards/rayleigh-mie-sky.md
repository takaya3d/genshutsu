# Rayleigh/Mie 単一散乱の空

源:     https://blog.maximeheckel.com/posts/on-rendering-the-sky-sunsets-and-planets/ (2026-07-25発見)
原理:   空の色 = 視線に沿って散乱してくる太陽光の積分。Rayleigh散乱はβ∝1/λ⁴で青が強く散る(昼の青空)。
        太陽が低いと光路(エアマス m≈1/(仰角+ε))が伸び、青が先に散り尽くして透過光が赤金になる(夕焼け)。
        Mie散乱は前方散乱(HG位相関数 g≈0.8)で太陽の周りの金色のハロー。フル積分せずとも
        T=exp(-β·k·m) と (1-T)·sunColor の解析近似で見た目は成立する。
再実装: sketches/験/rayleigh-mie-sky.html(マウス上下で太陽高度、昼→夕→暮の色変化)
モード適性: 静◎ 艶◎ 祭△
親和タグ: 鎮まり(雨上がりの空) / 余韻 / 金
罠:     βのスケールを1桁間違えると空が真っ黒or白飛び。地平線際の発散は ε で抑える。
        トーンマップ(1-exp(-x))を最後に必ず。生値だと夕色が飽和して品が失われる。
